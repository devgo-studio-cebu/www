Loading Intro — 3 Concepts for DEVGO Studio

Full-screen page load transition using animejs v4. All options follow the dark (#040906) / accent (#5fcba6) / uppercase brand language.

Concept A
DEVGO
S T U D I O

Character assembly + stagger reveal

Logo Character Assembly

Each letter of "DEVGO" flies in from off-screen with staggered timing, snaps into position, followed by "STUDIO" emerging below. Simple, bold, on-brand.

  • Matches existing navbar splitText animation pattern
  • Instantly communicates brand identity
  • Common pattern — less unique
Concept B

Dot-matrix logo that dissolves to hero

Dot-Matrix Brand Reveal

A grid of dots forms the DEVGO "D" shape. Dots light up in sequence, then the entire grid explodes/scatters outward to reveal the hero section underneath.

  • Visually connects to existing PixiJS particle grid
  • Unique, memorable brand moment
  • More complex to implement
  • Need precise dot placement per logo shape

Typing effect + progress bar reveal

Typewriter + Progress Bar

Console/Tech aesthetic. Status messages type out (Initializing… loading modules…), paired with a thin accent-colored progress bar. Fades to reveal the hero on completion.

  • Fits "dev" / software studio identity perfectly
  • Easy to localize / extend with real messages
  • Can feel gimmicky if overdone
  • Requires careful pacing to not feel slow
