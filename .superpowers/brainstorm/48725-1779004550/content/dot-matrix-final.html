Design Decisions

  • No text formation — Dots stay abstract throughout. The hero already has DEVGO branding; the intro is a transition, not a billboard.
  • Dev: No skip logic — Always play full intro in development. Skip for returning visitors will be gated behind an env flag or commented out.
  • Minimum hold — 1.5s minimum display time, even if assets load instantly. Prevents flash-of-loading.
  • Hero pre-initialization — PixiJS app starts in background (opacity: 0, pointer-events: none) during loading. Fades in when overlay completes.
  • animejs v4 API — Use anime() with .create option for dot multiplication, stagger() for sequenced reveals, and .outExpo easing for the fade.

What Gets Built

  • New component: LoadingOverlay.astro — fixed fullscreen container, z-index above navigation, houses animejs dot animations.
  • Modified: BaseLayout.astro — mount LoadingOverlay at body start, coordinate with hero script for completion signal.
  • Modified: hero.astro — initialize PixiJS in background, await load completion, trigger overlay teardown.
  • Assets: None. Purely animejs + CSS.
