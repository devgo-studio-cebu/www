Dot-Matrix Loading Intro — Refined Concepts

All variations use animejs v4, match the dark (#040906) palette, and transition seamlessly into your PixiJS particle hero.

Variation A
DEVGO
Dots snap into position

Random scatter → Logo formation → Scatter to hero

Scattered Dots → Logo Assembly

Dots spawn at random positions across the black screen. Using animejs stagger, they animate into precise grid positions forming "DEVGO" in block letters. Hold for 400ms, then each dot bursts outward with physics easing, revealing the hero beneath.

  • Clear brand moment before reveal
  • Staggered dot assembly is satisfying to watch
  • Scattering transition mirrors PixiJS particle movement
  • Need ~60-80 dots for readable "DEVGO" shape
  • Requires dot-position mapping for each letter
Variation B
Dots dissolve outward from center

Solid dot curtain → Progressive dissolve → Hero

Dot Curtain Dissolve

A dense grid of dots completely covers the hero section. An invisible radial mask expands from the center; as it grows, dots within the radius scale to 0 and fade. The dissolve follows a spiral/wave pattern, creating a "digital curtain opening" effect.

  • No need for logo-shape mapping — any grid works
  • Elegant "digital curtain" metaphor
  • Can tie dissolve speed to actual asset load progress
  • Less explicit "DEVGO" branding during loading
  • Requires many DOM nodes or canvas for performance
Variation C
Loading
Loading dots become hero particles

Loading dots drift → morph density → match hero grid

Particle Density Morph

Three loading dots pulse at the center. As assets load, they drift apart and multiply, transitioning from sparse loading state to the dense particle grid of your hero image. The loading state is literally the hero state at a lower resolution.

  • Seamless visual continuity with existing PixiJS hero
  • "Loading is just the hero at low-res" — clever concept
  • Requires only 3 dots to start, scales naturally
  • Subtle — some users may miss the loading moment
  • Needs hero to be initialized early (or faked)

Recommended: Blend A + B

Start with scattered dots assembling into "DEVGO" (Variation A), then instead of scattering to void, the dots hold position and dissolve outward from center (Variation B), seamlessly blending into the hero below. The hero PixiJS grid then feels like a higher-resolution continuation of the loading dots.
